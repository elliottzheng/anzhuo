# 安全说明

远窗是一个“让人从远处指挥电脑”的工具，所以安全必须说清楚。**用之前请把这一篇读完。**

## 一句话版本

> 远窗里的对话以“跳过权限确认”的方式运行。**谁能登录你的远窗网页（或你的钉钉账号），谁就能指挥这台电脑。** 登录密码是第一道也是最重要的一道门；“危险命令要你点头”是第二道，是安全带，**不是沙箱**。

## 它在保护什么、不保护什么

| 威胁 | 远窗怎么应对 | 你还需要做的 |
|---|---|---|
| 别人从网上打开你的远窗 | 网页只听 `127.0.0.1`，不对局域网、外网开放；所有页面和接口必须登录，没登录一律跳登录页或 401 | 外网访问时**一定用 HTTPS**，见 [外网访问](外网访问.md) |
| 猜密码 | 密码只存 PBKDF2-SHA256（30 万次迭代）指纹——macOS 在钥匙串，Windows 在配置目录旁的 `web_hash.json`；同一来源错 5 次锁 15 分钟，所有来源合计 1 小时内错 30 次全体锁 1 小时 | **设强密码**；不要和别处共用 |
| 会话被偷 | Cookie 设 `HttpOnly`、`SameSite=Lax`（HTTPS 下加 `Secure`），30 天有效；“登录的设备”里能看到每台设备并随时退出 | 手机丢了立刻全部退出 |
| 别的网站诱导你的浏览器发请求（CSRF） | 所有写接口校验请求来源必须和远窗同源 | — |
| 别人冒充你给钉钉机器人发消息 | 只认 `allowed_user_ids` 里的单聊，其余忽略并记日志 | 填对 ID；不要把机器人拉进群 |
| 密钥泄露 | 钉钉密钥、推送私钥、DeepSeek 密钥都只在 macOS 钥匙串，网页密码指纹 macOS 在钥匙串、Windows 在 `web_hash.json`，**都不在配置、仓库、日志里** | 别把自己的 `config.toml` 当成能公开的东西贴出去 |
| 日志泄露隐私 | 日志只记消息类型和长度。最近 100 条来往原文只留在本机数据目录的 `recent.jsonl`（排查用） | 想彻底不留就定期删这个文件 |
| AI 误操作（删文件、乱推送） | 危险的 Bash 命令先停下等你点“允许”（见下）；Codex 对话另有它自己的沙箱和审批 | 重要目录先备份、用 Git 管起来；别让它在你不愿意被改的目录里干活 |
| 搜索引擎收录你的网址 | 示例 nginx 配置带 `X-Robots-Tag: noindex, nofollow` | — |
| 服务器被当成代理 | 方案 A 里服务器只把域名转到隧道端口，不提供任何转发能力 | — |

## 危险命令确认：它拦什么、不拦什么

对话的权限模式是“全部放行”（不然你不在时它一步都走不动）。远窗在 Claude 对话的 **Bash 工具**前挂了一个钩子（`guard.py`），命令命中下面这些规则就停下，网页上出一张“等你确认”的卡片并弹手机通知，**你点“允许”才继续；点“不允许”或 20 分钟没回，当作不允许**：

- `git push`、`git reset --hard`、`git clean -f…`、`git branch -D`、`git stash drop/clear`、`git checkout -- …`、`git restore …`
- 数据库：`DROP TABLE`、`DELETE FROM`、`TRUNCATE TABLE`、`DROP DATABASE`
- `sudo`、`launchctl bootout/unload/remove`、`launchctl kickstart -k`
- 改磁盘：`diskutil erase/partition/zero`、`mkfs`、`dd if=`
- `chmod -R`、`chown -R`、`find … -delete`、`find … -exec rm`
- `ssh … rm / systemctl stop|restart|disable / reboot / shutdown`
- `rm`、`rmdir`、`trash` 删临时目录（`/tmp/`、`/var/folders/` 等）**以外**的东西
- Windows（cmd / PowerShell）：`del`、`rd /s`、`Remove-Item`、`format 盘符`、`diskpart`、`reg delete/add`、`shutdown`、`logoff`、`Stop-Service`、`Stop-Computer`、`sc stop/delete`、`Set-ExecutionPolicy`、`icacls`

**这套规则的边界，请务必知道：**

1. 它**只看 Bash 命令**。Claude 用“编辑 / 写入”工具直接改文件、覆盖文件，**不会被拦**。
2. 规则是**正则匹配**，不是语义理解。换个写法（比如把命令写进脚本再运行、用别的命令达到同样效果）就绕得过去。
3. Codex（GPT）对话走 Codex 自己的沙箱和审批：只读命令自动放行，其余先问；远窗把其中危险的交给你点头。
4. 所以它的定位是**防“手滑”的安全带**，不是防恶意的围墙。真正重要的东西，靠备份和 Git。

## 可选：AI 审核员

配置 `auto_review = true` 后，命中危险规则的命令会先交给**另一个 AI**（Sonnet，低档思考）结合“这一轮用户交代的事、最近几步在做什么、命令内容”判断放不放行；放行或拦下都会写进这一轮的报告，它出错或超时才退回来问你。

内置的判断标准是保守的：通常放行“删这次任务自己生成的临时文件、丢弃助手自己刚做的改动、能轻松撤销的操作”；**拦下**无关的危险操作、删你的原始资料、抹盘、强制推送、以及**默认不放行推送、上线、部署**。你可以在 `review_policy` 里用一段话**明说额外授权**什么（例如“推送到 dev 分支可以放行”）。

> 开审核员意味着你把“放不放行”交给了一个 AI。它的判断可能出错。是否开启、授权到什么程度，是你的决定。

## 远窗不替你预先授权任何事

给每个对话追加的固定要求（`sessions.build_instructions`）里只有“远窗和对话之间的约定”：怎么交截图和文件、“要你定”怎么写、怎么列步骤、后台命令的使用限制。**里面没有“提交、推送、上线直接做不用问”这类授权**。想要这类行为，请你自己写进配置的 `extra_instructions`，并清楚它的后果。

## 数据去了哪里

远窗不会把你的数据发给开发者或任何第三方服务器。数据会去的地方：

| 去哪 | 什么数据 | 什么时候 |
|---|---|---|
| Anthropic（经 Claude Agent SDK） | 你的对话、对话里读到的文件内容——和你平时用 Claude Code 完全一样 | 用 Claude 对话时 |
| OpenAI（经 Codex） | 同上 | 用 GPT 对话时 |
| Anthropic（Haiku） | 给对话起名（你的第一句话和回复开头）；打开翻译后，用它翻译英文（没有 DeepSeek 密钥时）；开了审核员时用 Sonnet 看命令和上下文 | 对应功能开着时 |
| DeepSeek（`api.deepseek.com`） | **含大段英文的回复原文**，用来翻译成中文 | **只有同时满足两件事才会**：你把 `translate_english` 改成 `true`，并且自己在钥匙串里放了 DeepSeek 密钥。默认两者都不满足，什么都不会发出去 |
| 钉钉服务器 | 你和机器人的消息、做完的报告、图片和文件 | 开了钉钉入口时 |
| Apple / Google 的推送服务 | 通知的标题和一句短话 | 开了手机通知时 |
| 你自己的服务器 | 加密后的网页流量（方案 A 里 nginx 终止 HTTPS，所以服务器**能看到**网页内容，请用你信得过的服务器） | 用外网访问时 |

## 合规

远窗是“个人在自己的电脑上，用自己的订阅调用官方的 SDK 和 CLI”。**不要把它做成多人共用的服务、不要转卖访问权**——那样可能违反 Anthropic / OpenAI 的订阅条款。使用前请自己再看一遍它们最新的条款。

## 加固清单

- [ ] 网页密码是强密码，没和别处共用
- [ ] 外网访问用 HTTPS，`web_base` 写的是 `https://…`
- [ ] 手机有锁屏密码；丢了知道怎么退出所有设备（“⋯” → 登录的设备）
- [ ] 重要项目用 Git 管着、有备份
- [ ] 没把 `~/.config/anzhuo/config.toml` 和 `~/.local/share/anzhuo/` 当成能公开的东西
- [ ] 清楚自己是否开了 `auto_review`、写了什么 `review_policy` / `extra_instructions`
- [ ] （用钉钉）`allowed_user_ids` 只有你自己
- [ ] 想暂停时：双击 `scripts/停用远窗.command`

## 报告安全问题

发现漏洞请**不要**直接发公开 issue。用 GitHub 仓库的 **Security → Report a vulnerability**（私密报告）联系维护者，写清楚复现步骤和影响。
